Menambahkan novel baru

Lingxi adalah situs statis. Novel diterbitkan dengan menambahkan data terjemahan ke repository GitHub—tidak perlu backend, database, atau API.

Cara paling mudah

  1. Buka repository GitHub, lalu masuk ke data/novels.json.
  2. Tekan ikon pensil untuk mengedit file.
  3. Salin salah satu objek novel contoh dan ubah ID, judul, penulis, sinopsis, genre, status, serta bab-babnya.
  4. Setiap bab memiliki title dan content. Pisahkan paragraf dengan dua baris baru (\n\n dalam JSON).
  5. Simpan perubahan dengan Commit changes. Setelah GitHub Pages selesai memperbarui situs, novel akan muncul di beranda.

Gunakan format JSON yang valid. Jangan hapus tanda koma pemisah antarobjek, dan jangan publikasikan karya yang tidak kamu miliki haknya.

}
